# SHYNI MATE

shyni 미디어 서버를 위한 스캔 매니저입니다.

들어온 항목을 정해진 개수만큼 동시에 처리합니다. 항목마다 VFS 새로고침 → 스캔 전송 → 결과 확인 순서로 진행하고, VFS 새로고침은 쓸지 말지 선택할 수 있습니다. 동시 스캔 수는 설정에서 정합니다 (기본 2개).

## 설치

1. SHYNI MATE → 설정에서 shyni 주소와 토큰을 입력하고 저장합니다.
2. 스캔 → 설정에서 동시 스캔 수, VFS 새로고침 규칙, shyni 경로 매핑을 확인합니다.

## 기능

- 모드: ADD, `REMOVE_FILE`, `REMOVE_FOLDER`, REFRESH
- 스캔 전에 rclone VFS 새로고침 (쓸지 말지 선택 가능, 규칙 기반 경로 변환)
- shyni 작업을 주기적으로 확인해서 완료·실패를 확정하고, 끝나면 콜백으로 알림
- 탐색 페이지에서 우클릭으로 새로고침·스캔 실행
- 대시보드 탭: 라이브러리별 VFS 새로고침·스캔 실행과 상태 표시
