전체 현황

메타는 코드·설명·연도·표지 같은 작품 정보입니다. 메타 메뉴를 열면 라이브러리별 카드가 나옵니다. 카드에는 전체 개수와 메타가 없는 미디어 수, 코드·설명·연도·표지가 없는 수가 나옵니다.

숫자는 메타 목록을 조회해서 저장해 둔 결과의 요약에서 가져오므로, 상세 화면과 개수가 같습니다. 아직 목록을 조회한 적이 없는 라이브러리는 대시보드용으로 미리 계산해 둔 통계에서 가져옵니다.

카드마다 '캐시 N분 전'이 붙어 있어, 이 숫자가 언제 만든 캐시인지 알 수 있습니다. 머리말의 '표시'에서 안 볼 라이브러리를 숨길 수 있습니다. 숨긴 건 전체 현황에서만 안 보이고, 상세에서는 그대로 고를 수 있습니다. 정렬은 기본이 메타 없음 수 내림차순이고, 머리말에서 바꿀 수 있습니다.

상세 보기

라이브러리를 고르면 메타가 없는 미디어만 목록으로 나옵니다. 요약 줄은 두 줄입니다. 첫 줄은 전체 미디어 수와 그중 메타가 없는 수, 둘째 줄은 코드·설명·연도·표지가 없는 수입니다.

검색과 정렬, 페이지 이동이 됩니다. 카드에는 표지와 폴더 전체 경로가 나옵니다.

메타 새로고침

[전체 메타 새로고침]은 메타가 없는 항목만 골라 채웁니다. 코드가 없는 항목이 대상이고, 폴더 라이브러리는 표지가 없는 항목이 대상입니다. [선택 메타 새로고침]은 목록에서 고른 것만 채웁니다. 진행은 버튼 아래 상태 줄에서 보이고, 끝난 뒤에는 조회 버튼을 눌러 다시 불러오면 됩니다.

취소는 대시보드에서 합니다. 메타 새로고침이 도는 라이브러리 카드 오른쪽의 [취소] 버튼을 누르면 멈춥니다. 버튼을 누르면 '취소중'으로 바뀌고, 멈춘 것이 확인되면 '메타 새로고침 취소됨'으로 표시됩니다.

조회와 모두 조회

메타 화면은 저장된 캐시를 보여 줍니다. 자동으로 다시 계산하지 않습니다. 오래됐다고 판단되면 [조회]로 이 라이브러리를, [모두 조회]로 전체 라이브러리를 다시 읽어옵니다.

데이터가 있으면 조회 버튼은 '최신으로 조회'로 바뀝니다. 조회 중에는 버튼이 '조회 취소'로 바뀌어, 누르면 멈추고 기존 데이터를 씁니다.

Relay를 켜야 보입니다

메타는 Relay로만 읽습니다. Relay가 꺼져 있으면 안내만 나오고 목록이 비어 있습니다. 설정 > Relay에서 켤 수 있습니다.

Relay 설정 방법은 설정 > Relay 화면의 'Relay 매뉴얼' 탭을 봐 주세요.

화면 갱신

  • 조회 중일 때만 진행률이 갱신됩니다 (0.7초마다). 조회가 끝나면 목록이 한 번에 바뀝니다.
  • 메타 새로고침이 도는 동안에는 1초마다 진행 상태가 갱신됩니다.
  • 전체 현황 개수는 자동으로 바뀌지 않습니다. 페이지를 다시 열거나 조회하면 최신 개수가 보입니다.
  • 목록은 기본적으로 저장해 둔 결과를 보여 줍니다. 최신 상태로 다시 계산하려면 '최신으로 조회'를 눌러 주세요. 화면에 "캐시 데이터 기준 (N분 전)"처럼 기준 시각이 표시됩니다.
  • 전체 현황의 통계는 최대 6시간까지 낡을 수 있습니다. 통계는 백그라운드에서 주기적으로 다시 계산합니다.
  • 메타 새로고침이 끝나도 목록이 자동으로 바뀌지 않습니다. "조회 버튼을 눌러 다시 불러와 주세요" 안내가 나오면 조회 버튼을 눌러 주세요.
