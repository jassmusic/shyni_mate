shyni_mate 매뉴얼

소개 설치 기능 shyni 최신 버전 확인 라이선스

소개

shyni 전용 스캔 매니저.

수신 항목을 정해진 수만큼 동시 처리한다. 항목마다 VFS 새로고침 → 스캔 전송 → 결과 확인 순서로 진행하며, VFS 새로고침은 여부를 선택할 수 있다. 동시 스캔 수는 설정으로 조절한다 (기본 2).

설치

  1. SHYNI MATE → 설정에서 shyni 주소와 토큰을 입력하고 저장한다.
  2. 스캔 → 설정에서 동시 스캔 수, VFS 새로고침 규칙, 샤이니 경로 매핑을 확인한다.
  3. shyni 최신 버전을 대시보드에서 보려면 설정 > shyni 연결의 GHCR 토큰 칸에 토큰을 입력한다. 자세한 내용은 'shyni 최신 버전 확인' 절을 봐 주세요.

기능

  • 모드: ADD, REMOVE_FILE, REMOVE_FOLDER, REFRESH
  • 스캔 전송 전 rclone VFS 새로고침 (사용 여부 선택 가능, 규칙 기반 경로 변환)
  • shyni job 폴링으로 완료/실패 확정, 완료 시 콜백 통지
  • 탐색 페이지에서 우클릭으로 새로고침·스캔 실행
  • 대시보드 탭: 라이브러리별 VFS 새로고침·스캔 실행과 상태 표시
  • shyni 최신 버전 표시: GHCR에서 최신 버전을 확인해 대시보드에 표시한다 (GHCR 토큰 필요)

shyni 최신 버전 확인

대시보드의 shyni 서버 카드에서 지금 쓰고 있는 버전이 최신인지 확인할 수 있습니다. GHCR(깃허브 컨테이너 레지스트리)에서 shyni 최신 버전을 가져와 비교합니다.

GHCR 토큰 입력

설정 > shyni 연결의 GHCR 토큰 칸에 토큰을 입력하고 저장합니다. 토큰은 깃허브에서 발급받은 개인 액세스 토큰으로, read:packages 권한이 있으면 됩니다.

토큰을 입력하지 않으면 최신 버전 표시는 나오지 않고, 지금 버전만 표시됩니다.

표시 방식

  • 최신버전 (초록 라벨): 지금 버전이 최신과 같습니다.
  • 업데이트 필요 (주황 라벨): 새 버전이 있습니다. 버전 줄에는 새 버전이 화살표와 함께 표시됩니다.
  • 빌드 줄: 실행 중인 빌드 날짜와 커밋 SHA(7자)를 보여 줍니다. 새 빌드가 있으면 화살표 뒤에 새 빌드 정보가 붙습니다.

조회 주기

대시보드를 열 때만 조회합니다. 결과는 1시간 동안 저장해 두고, 그 안에서는 다시 조회하지 않습니다. 조회에 실패하면 10분 뒤에 다시 시도합니다. 대시보드를 열지 않으면 조회하지 않습니다.

처음 토큰을 입력한 뒤에는 대시보드를 한 번 새로고침해야 라벨이 보입니다. 첫 로딩에서는 조회가 시작만 되고, 두 번째 로딩부터 표시됩니다.
